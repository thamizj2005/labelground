🤖 AI Features Guide

Labelground uses an AI ensemble (YOLO-World + Grounding DINO + SAM) to help you annotate faster. Here's what every AI button and toggle does:

🤖
AI Auto-Annotate
Top Bar → AI Group

Runs AI on the currently selected image only. It uses YOLO-World and Grounding DINO models to detect your project classes. If you have a custom-trained model available, it uses that instead for higher accuracy.

When to use: When you want to quickly get AI suggestions for a single image before reviewing. After the AI annotates, a yellow border appears on the image thumbnail. You then review and click "✅ Save & Verify" or "🚀 Confirm & Next" to accept.

🚀
Batch AI Annotation
Top Bar → AI Group

Annotates all pending (un-annotated) images in your project in the background automatically. A progress bar appears in the top toolbar showing real-time progress.

When to use: When you have freshly imported a large batch of images and want to get AI suggestions for all of them at once before you start reviewing. This runs as a background task — you can continue working while it runs.

✨
Auto-AI Checkbox (Auto)
Top Bar → AI Group → "Auto" toggle

When checked, AI automatically runs on every image you navigate to that hasn't been annotated yet. Think of it as a "live streaming AI assistant".

When to use: Enable this when you want to move through images quickly — the AI pre-annotates each image as you arrive so you only need to verify and confirm.

🎓
Auto-Training Checkbox
Left Sidebar → "Auto-Training 🎓"

When enabled, the system automatically triggers a model training run in the background when you accumulate enough verified (human-annotated) images. Training milestones: first 10, then every 20 images.

What it does: Trains a custom YOLO model specifically on your project's data. After training, this custom model is used instead of the base zero-shot models, dramatically improving accuracy for your specific objects.

Recommendation: Keep this ON. The model improves iteratively — the more you verify, the better the AI suggestions become.

🔧
Auto Fine-Tuning Checkbox
Left Sidebar → "Auto Fine-Tuning 🔧"

Similar to Auto-Training but fine-tunes an existing custom model incrementally rather than training from scratch. This is faster and uses newer annotations to refine the model.

Difference from Auto-Training: Auto-Training builds a model from scratch on all verified data. Auto Fine-Tuning takes the existing model and continues refining it. Both can be ON simultaneously for best results.

🎓
Train Model Button
Top Bar → "🎓 Train"

Opens the training dialog where you can manually kick off a custom model training. You can configure training epochs (50–300 recommended) and a data augmentation multiplier to expand your dataset.

When to use: When you have verified at least 10–20 images and want to manually trigger training immediately without waiting for the auto-training milestone.

🧠
Confusion Sort (Active Learning)
Left Sidebar → 🧠 button

Sorts your image list based on AI confidence scores — images where the AI is least confident (low-confidence detections) appear first. This is an Active Learning technique.

Why it matters: Annotating images the AI struggles with gives the most training value. By focusing on confusing cases, each annotation you make improves the model more than annotating easy images would.

🔍
Verification Mode
Left Sidebar → 🔍 button

Filters the image list to show only AI-annotated images waiting for human verification. This gives you a focused review queue.

Recommended workflow: Run Batch AI → Switch to Verification Mode → Review and confirm AI annotations one by one → Let Auto-Training retrain the model.

📝 Complete Workflow Guide

💡 Recommended AI-Assisted Workflow

Import Images → Run Batch AI → Review & Verify in Verification Mode → Auto-Training creates better model → Repeat.

1 Create Project

Go to Dashboard → Create New Project. Choose annotation type: Bounding Box (for object detection), Polygon (for segmentation), or Keypoints. Add class labels and assign colors.

2 Import Data

Click 📥 Import in the top bar. You can import individual images, a full folder, or extract frames from a video at a custom FPS (e.g., 1 FPS = 1 frame per second).

3 Run Batch AI

Click 🚀 Batch to let AI annotate all your images automatically. Monitor progress in the top toolbar. Meanwhile you can start reviewing already-processed images.

4 Annotate & Verify

Manually adjust or verify AI annotations:
• BBox: Drag on canvas to draw
• Polygon (Draw Box): Draw a box around object → SAM segments it
• Polygon (Click): Single click on object → SAM auto-segments
• Manual Polygon: Click to place points, right-click to finish
• Keypoints: Click to place anatomical points

Press V or click ✅ Save & Verify to mark as human-verified.

5 Model Improves Automatically

When you have 10+ verified images, Auto-Training kicks in and trains a custom model. After training, the AI uses your custom model instead of the base zero-shot model. The more you verify, the smarter the AI becomes.

6 Export Dataset

From the Dashboard, go to Export Project. Choose format (YOLO, COCO, Pascal VOC, LabelMe, JSON), configure train/val/test splits, and optionally apply image augmentation to multiply your dataset size.

ℹ️ About Labelground

Labelground is a professional offline AI-assisted annotation platform designed for maximum data privacy and annotation speed.

🤖 AI Models

  • YOLO-World (zero-shot detection)
  • Grounding DINO (text-guided detection)
  • SAM (Segment Anything Model)
  • Custom YOLO (your trained model)

🛠️ Tech Stack

  • Python + FastAPI (backend)
  • Vanilla JS + Canvas API (frontend)
  • SQLite (local database)
  • Ultralytics YOLO (training)
🔒 100% Offline & Private
All data stays on your machine. No cloud uploads, no external API calls. Your dataset never leaves your local environment.
